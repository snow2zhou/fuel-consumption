# 油耗记录 APP

一个可在安卓手机上安装使用的油耗记录应用，基于 Vue3 + Vant + Capacitor 开发。

## 功能特性

### 1. 加油记录
- 记录加油时间、加油量（L）、油价（元/L）、费用（元）、总行驶里程（km）、预计可行驶里程（km）
- 支持"是否加满油箱"标记（影响油耗计算准确性）
- 支持油号选择（92#/95#/98#/柴油）
- 费用自动计算（加油量 × 油价），支持手动覆盖
- **顶部双入口**：左侧「今日油价 + 调价方向」直达油价页，右侧「调价日历」以日历形式标出历次调价日与涨跌（橙色 ↑/↓）
- **参考油价自动带出**：新建记录时按「加油日期 + 油号」查本地价格记录中「生效日 ≤ 加油日期」最新的一条，自动预填并标注「参考价 x.xx 元/升（生效日 起 · 省最高零售价）· 可修改」；手动改过后不再覆盖，改日期/换油号会重新查，查不到则清空。可在设置里关闭
- 保存时把参考价快照进记录（`priceRef`），以后价格记录被清理也不影响历史统计
- **自动对比计算**：新增加油记录后，自动与上一次加油记录对比，计算：
  - 间驶里程 = 本次总里程 - 上次总里程
  - 百公里油耗 = 本次加油量 ÷ 间驶里程 × 100（L/100km）
  - 每公里费用 = 本次加油量 × 上次油价 ÷ 间驶里程（元/km）
  - 期间总费用 = 本次加油量 × 上次油价

### 2. 行程快照
- 记录停车后的相关里程数据：总行驶里程、本次行驶里程、估计可行驶里程
- 自动计算"估计总行驶里程 = 总行驶里程 + 估计可行驶里程"

### 3. 统计报表
- 概览统计：平均百公里油耗、平均每公里费用、累计加油量/费用/里程、平均油价
- **油价对比**：我的加权均价 vs 省最高零售价均价、累计多花/省多少、每升差额，并标注有参考价的记录占比
- 图表展示：百公里油耗趋势（折线图）、每次加油费用（柱状图）、油价变化趋势（**双线**：实际单价 + 省最高零售价）
- 一键导出 Excel：加油记录、行程快照均可导出为 .xlsx 文件

### 4. 设置
- 默认油号偏好设置
- 油耗单位切换
- 默认首页切换（启动后自动进入所选页面，默认「行程」）
- 油价地区（省份）、调价提醒开关、**加油自动带出参考价**开关、**油价数据源**（内置 4 个 + 自定义，可切换/配凭据）
- 油价记录入口（`/oil/prices`）：查看/新增/修改/删除本地价格记录
- 节假日数据：查看已收录年份、按年获取国务院放假安排（用于精确计算 10 个工作日）、清除已获取数据
- 数据管理（查看各记录数与「待导出加油记录」条数；清空加油记录/行程快照/全部数据，全部含发票）
- 数据迁移：导出/导入 JSON（含发票，支持覆盖与合并两种模式）

### 5. 发票
- **发票 = 开票主体**：名称/抬头、开户行、银行账号、税务账号（税号）、联系电话、备注（抬头信息一处维护，多条加油共享）
- **发票链接、开票日期、是否已导出都在加油记录上**：一张发票主体可对应多次加油，每次加油各持自己的电子票信息与报销进度（开票日期默认当天）
- 加油记录可关联一张发票主体（外键 `invoiceId`）；加油列表状态标签为三态：**已导出** / **待导出**（已填链接）/ **已关联发票**（仅关联）
- 发票界面用法：**① 顶部选择一张发票**（卡片与弹层均标注"未导出 n/总数"进度）→ **② 查看该发票的抬头信息**（卡片放大排版：抬头 18px、字段值 16px，税号/银行账号等宽字体；联系电话点一下即可拨号）→ **③ 下方列出关联的加油记录**（开票日期、发票链接、可点击切换的「已导出」标签，支持 全部/未导出/已导出 筛选与全选）→ **④ 勾选若干记录后点「复制」**
- **复制输出**：每行一条 `开票日期：发票链接`，一行一条；复制成功后所选记录自动标记为**已导出**（导出即报销完成），若有记录未填链接会在提示中告知条数
- 底部操作条还支持批量「标记已导出 / 标记未导出」（不复制、仅改状态），并显示已选条数与合计金额
- 复制在 PWA / 安卓 WebView 下自动降级兼容，保证可用

### 6. 油价
- 从「加油记录」页顶部油价卡进入 `/oil`：**今日油价 + 下次调价窗口 + 预计涨跌**一眼可见
- 顶部选地区（31 省，点开弹层选择，已查过的显示缓存价；默认记住上次选择）
- 核心回答「**要不要等调价后再加**」：
  - 预计上调 / 下调 / 搁浅（不足 50 元/吨），并给出折合 **元/升**、距门槛的安全边际、**第 N/10 个工作日**与**把握度**
  - 结合本 App 数据算出「我的每公里成本」「加满一箱多花/省多少」「续航撑不撑得到调价日」
- 数据缓存 6 小时，断网/限额时回退缓存并标注时间；匿名接口额度很小（实测 5 次/天），可在设置里填免费 API Key
- **调价测算全来源可用**：来源自带测算直接用；没带的（含自定来源）用东方财富布伦特/WTI 日 K **自算**变化率与预计幅度（标「自算」，6h 缓存），不再依赖单一接口
- **调价提醒**：调价日当天/前一天打开 App 会弹一次提醒（每个调价窗口只提醒一次，设置里可关闭）
- **价格记录（自己攒的曲线）**：每次查询时若价格有变化就记一个点，逐步形成阶梯曲线，并列出最近变动与累计涨跌；不足 2 个变更点时不画图。记录随 JSON 备份一起迁移
- 价格记录的日期是**生效日**（该价从这日起执行，直到下次调价窗口），不是"打开 App 的那天"；查询时取「生效日 ≤ 加油日期」中最新的那条，因此补录前几天/几周的加油也能对上当时的价
- **历史油价查看**：油价页可选任意过去日期，显示当天各油号的生效价；缺油号时自动从**东方财富·发改委调价数据**（2009 年以来历次调价 + 31 省明细，JSONP 直连）补齐，并可一键存入本机记录
- **多数据源（可切换）**：内置 7 个 ——「极数本源」（免 Key，含调价测算）/「小小 API」「澄曜 API Hub」（均免 Key，一次返回全国 31 省）/「万维易源」「天行数据」「接口盒子」（需免费 Key）/「手动录入」；设置或油价页顶部一键切换，凭据按来源分别保存（仅本机）
- **自定义来源**：设置里可添加任意 JSON 接口或网页，地址用 `{province}` / `{provinceEnc}` 占位，支持自定义请求头；JSON 会自动嗅探价格（数组条目、`{n92:…}`、`{data:{data1:{'92':…}}}` 等形态）
- **解析失败自动降级**：网页来源或解析不出价格时，页面直接内嵌该网页，并提供「在浏览器打开 / 换个来源 / 手动录入」三种出口；手动录入的价格会记入价格曲线
- 时间口径按**真实工作日**计算：内置国务院放假安排（含调休上班日），跨春节/国庆自动跳过整段假期；不提供调价窗口的数据源会按「生效日 + 10 个工作日」推算并标注「推算」
- 次年放假安排公布后，可在设置里按年获取（不必等 App 更新）；未公布时会明确提示，不会写入空数据
- 测算口径依据发改委《石油价格管理办法》，页面标注「以发改委通知为准」

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器（浏览器调试）
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 本地使用

不想用命令行，可直接双击项目根目录的批处理脚本（Windows）：

| 脚本 | 作用 | 访问地址 |
|------|------|----------|
| `run-dev.bat` | 安装依赖并启动开发服务器（带热更新） | http://localhost:5173 |
| `build.bat` | 安装依赖并构建生产版本到 `dist/` | — |
| `run-preview.bat` | 构建并预览生产版本 | http://localhost:4173 |

> 双击 `run-dev.bat` / `run-preview.bat` 会自动打开浏览器，关闭窗口即停止服务。
> 首次运行会自行 `npm install`，请确保已安装 Node.js（https://nodejs.org）。

**默认首页**：在「设置 → 默认首页」中可选择启动后进入的页面（行程 / 加油 / 发票 / 统计 / 设置），默认「行程」，下次启动生效。

## 打包安卓 APK

需要先安装 Java JDK 17 和 Android Studio。

```bash
# 1. 构建前端
npm run build

# 2. 添加安卓平台（首次执行）
npm run cap:add:android

# 3. 同步资源到安卓工程
npm run cap:sync

# 4. 打开 Android Studio 进行打包
npm run cap:open:android
```

在 Android Studio 中：
1. 等待 Gradle 同步完成
2. 菜单 Build → Build Bundle(s) / APK(s) → Build APK(s)
3. 生成的 APK 在 `android/app/build/outputs/apk/debug/` 目录下

## 油耗计算说明

百公里油耗的准确计算依赖一个前提：**每次加油都加满油箱**。

因为本次加的油，实际上是上次加油到本次加油期间消耗掉的。所以：

```
百公里油耗 = 本次加油量 ÷ (本次总里程 - 上次总里程) × 100
```

只有当本次与上次都"加满"时，该计算才准确。本应用在未加满时会提示"无法准确计算油耗"。
